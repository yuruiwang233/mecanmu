LT 线性扳机控制前进油门，RT 线性扳机控制倒车油门；右摇杆只选方向（忽略力度），LT 沿摇杆指向前进、RT 沿反方向倒车。右摇杆居中时按 LT 默认前进、按 RT 默认后退。

模式一 · 左摇杆（优先）：推左摇杆 → 麦轮全向移动，方向 = 摇杆偏移方向，速度 = 摇杆偏移幅度。左摇杆生效时自动接管，LT 油门无效。

模式二 · LT / RT + 右摇杆：左扳机 LT = 前进油门，右扳机 RT = 倒车油门（均为线性速度），右摇杆 = 方向（忽略力度）。LT 沿摇杆指向前进、RT 沿反方向倒车；右摇杆居中时 LT 默认直行前进、RT 默认直行后退。两扳机同按相互抵消。

两种模式相互独立：左摇杆扳出即切模式一；左摇杆回中自动切回模式二（LT / RT + 右摇杆）。

原地转圈：按住 X = 向左原地转圈，按住 B = 向右原地转圈，松开即停；按键期间优先级最高，临时接管摇杆 / 扳机。

手柄需先用蓝牙配对（Windows 设置 → 蓝牙 → 添加设备 → Xbox Wireless Controller），用 Chrome / Edge 打开本页并保持前台，按手柄任意按键激活检测。
