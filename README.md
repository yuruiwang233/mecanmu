# ESP32-S3 麦克纳姆轮全向小车

基于 **ESP32-S3 + TB6612 + 麦克纳姆轮（ABBA 安装）** 的全向移动小车，提供纯网页（HTML/CSS/JS）遥控界面，通过 **Web Bluetooth（BLE）** 连接，支持**手机触屏**与**蓝牙手柄**两种遥控方式，无需安装 App。

- 主控：ESP32-S3 N16R8
- 电机：TT 减速电机 × 4
- 驱动：TB6612FNG × 2
- 轮子：麦克纳姆轮，ABBA 安装
- 通信：BLE（Nordic UART Service 风格私有协议）
- 前端：原生 HTML / CSS / JavaScript，零依赖、零构建

## 功能特性

- **全向移动**：前进 / 后退 / 左右横移 / 斜向移动 / 原地自转。
- **手机遥控**：触屏方向键 + 原地左转 / 右转按钮 + 速度滑块，支持键盘（WASD / 方向键 / 空格）。
- **手柄遥控**：
  - Xbox 风格**手柄图形实时映射**（摇杆十字、LT/RT 扳机、ABXY、肩键、十字键）。
  - 两个**摇杆角度圆盘**与手柄图形一一对应，显示角度 / 力度 / X / Y。
  - LT / RT **线性数值**实时显示。
- **两套相互独立的手柄控制逻辑**：
  1. **左摇杆**：方向 + 速度一体（优先）。
  2. **LT / RT + 右摇杆**：LT 前进油门、RT 倒车油门，右摇杆只管方向。
- **按键原地转圈**：按住 **X** 向左原地转圈，按住 **B** 向右原地转圈（优先级最高）。
- **安全机制**：1 秒收不到指令自动停车；断开蓝牙立即停车。
- **无啸叫**：PWM 频率 20kHz（超声波范围）。
- **单电机测试**：串口 / BLE 发送 `T1~T4` 单独驱动四个电机，方便排查。

## 接线说明

### 电机命名（俯视）

```
          前
   L1（左前）    R1（右前）
   L2（左后）    R2（右后）
          后
```

麦克纳姆轮按 **ABBA** 安装：左前 = A、右前 = B、左后 = B、右后 = A。

### TB6612 与电机

- **C1（左侧 TB6612）**
  - L1 电机「+」→ **AO1**，「−」→ AO2
  - L2 电机「+」→ **BO1**，「−」→ BO2
- **C2（右侧 TB6612）**
  - R1 电机「+」→ **AO1**，「−」→ AO2
  - R2 电机「+」→ **BO1**，「−」→ BO2
- AO1 / BO1 同时为正即「前进」，左右两侧前进方向一致。
- 两片 TB6612 的 **STBY 直接接 3.3V**（常使能，不占用 GPIO）。
- VM 接电机电源，VCC 接逻辑电源（3.3V 或 5V，按模块），GND 共地。

### ESP32-S3 引脚

| 电机 | 驱动通道 | PWM | IN1 | IN2 |
|------|----------|-----|-----|-----|
| L1 左前 | C1 – A | **GPIO1** | GPIO2 | GPIO3 |
| L2 左后 | C1 – B | **GPIO4** | GPIO5 | GPIO6 |
| R1 右前 | C2 – A | **GPIO7** | GPIO8 | GPIO9 |
| R2 右后 | C2 – B | **GPIO10** | GPIO11 | GPIO12 |

> 如需更改引脚，修改 `mecanum_car.ino` 顶部的 `PIN_xxx` 宏即可。

## 麦轮运动学原理

定义车体速度（归一化到 −1~1）：

- `vx`：前进为 **+**，后退为 −
- `vy`：左移为 **+**，右移为 −
- `w` ：逆时针（左转）为 **+**，顺时针为 −

四轮速度（ABBA）：

```
L1 = vx - vy - w
R1 = vx + vy + w
L2 = vx + vy - w
R2 = vx - vy + w
```

计算后取四轮绝对值的峰值 `peak`，若 `peak > 1` 则全部除以 `peak` 归一化，保证任意组合下轮速都不超过最大值。前端 `app.js` 与后端 `mecanum_car.ino` 使用完全一致的公式。

典型方向四轮输出（L1, R1, L2, R2）：

| 动作 | vx, vy, w | 四轮输出 |
|------|-----------|----------|
| 前进 | (1,0,0) | +, +, +, + |
| 后退 | (−1,0,0) | −, −, −, − |
| 左移 | (0,1,0) | −, +, +, − |
| 右移 | (0,−1,0) | +, −, −, + |
| 原地左转 | (0,0,1) | −, +, −, + |
| 原地右转 | (0,0,−1) | +, −, +, − |

## 通信协议

BLE 使用 Nordic UART Service 风格的 UUID：

- Service UUID：`6e400001-b5a3-f393-e0a9-e50e24dcca9e`
- Characteristic UUID：`6e400002-b5a3-f393-e0a9-e50e24dcca9e`
- 广播设备名：`MecanumCar-S3`
- 每条指令以换行符 `\n` 结尾，支持一次写入多条。

| 指令 | 说明 |
|------|------|
| `F` / `B` | 前进 / 后退 |
| `L` / `R` | 左平移 / 右平移 |
| `S` | 停止（滑行模式） |
| `TL` / `TR` | 原地左转 / 原地右转 |
| `V<0~255>` | 设置手机模式最大速度，如 `V180` |
| `M<L1>,<R1>,<L2>,<R2>` | 直接设置四轮 PWM（−255~255），如 `M255,-255,255,-255` |
| `T1` / `T2` / `T3` / `T4` | 单独测试 L1 / L2 / R1 / R2（运行 3 秒自动停） |

- 手机模式使用 `F/B/L/R/S/TL/TR/V` 离散指令。
- 手柄模式使用 `M` 连续指令。
- `T1~T4` 既可通过 BLE 发送，也可在 Arduino 串口监视器直接输入。

## 控制方式说明

### 一、手机遥控

- **方向键**：按住「前进 / 后退 / 左移 / 右移」持续运动，松开停止。
- **原地左转 / 右转**：橙色按钮，按住持续自转。
- **速度滑块**：范围 80~255，松手后写入固件。
- **键盘**：W/↑ 前进，S/↓ 后退，A/← 左移，D/→ 右移，空格停止。
- 长按期间前端会持续重发指令，保证不会被安全看门狗误停。

### 二、手柄遥控

先在系统蓝牙中配对手柄（推荐 Xbox 兼容、`standard` 映射），用 Chrome / Edge 打开页面并保持前台，按任意按键激活。

**模式一 · 左摇杆（优先）**

- 摇杆推向哪个方向，车就往哪个方向全向移动。
- 摇杆偏移幅度 = 速度；左摇杆扳出死区即接管，此时 LT/RT 无效。

**模式二 · LT / RT + 右摇杆**（左摇杆回中时）

- **LT**：线性前进油门；**RT**：线性倒车油门。
- **右摇杆**：只决定方向（忽略力度）。
  - LT 沿摇杆指向前进，RT 沿摇杆**反方向**倒车。
  - 右摇杆居中时：LT 默认直行前进，RT 默认直行后退。
  - LT、RT 同按相互抵消。

**原地转圈（最高优先级）**

- 按住 **X**：向左原地转圈；按住 **B**：向右原地转圈；松开即停。
- 按键期间临时接管摇杆 / 扳机，松开后恢复原控制。

手柄界面还提供：手柄图形映射、LT/RT 线性数值条、左右摇杆角度圆盘、按键状态 chips、四轮 PWM 实时数值。

## 编译与烧录（后端）

1. 安装 [Arduino IDE](https://www.arduino.cc/en/software)（2.x）。
2. 添加 ESP32 开发板支持：
   - 文件 → 首选项 → 附加开发板管理器网址，填入：
     `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
   - 工具 → 开发板 → 开发板管理器，搜索 **esp32** 并安装，**需要 3.0.0 或更高版本**。
3. 打开 `mecanum_car/mecanum_car.ino`。
4. 工具设置：
   - 开发板：**ESP32S3 Dev Module**
   - USB CDC On Boot：**Enabled**（需要串口时）
   - Flash Size / PSRAM：按模块（N16R8 选 8MB Flash、8MB PSRAM）
   - 其余默认。
5. 选择正确端口，点击上传。
6. 打开串口监视器，波特率 **115200**，可看到启动日志，并可直接输入 `T1~T4` 等指令测试。

> 固件使用 ESP32 核心自带的 BLE 库与 `analogWrite`（LEDC），无需额外安装库。

## 前端运行

前端为纯静态文件，但 **Web Bluetooth 与 Gamepad API 要求安全上下文**（`https://` 或 `localhost`），请使用 **Chrome / Edge**。

方式一：本地服务器（推荐）

```bash
# 在项目根目录执行
python -m http.server 8000
# 浏览器打开
http://localhost:8000/
```

方式二：直接用 `http://localhost` 或部署到任意 HTTPS 静态托管后访问。

操作流程：

1. 打开页面 → 点击「连接蓝牙」→ 选择 `MecanumCar-S3`。
2. 连接成功后选择「手机遥控」或「手柄遥控」。
3. 手柄模式请先在系统中配对手柄并按任意键激活。

> 直接双击 `index.html`（`file://`）通常无法使用蓝牙，请务必通过 localhost / https 访问。

## 参数配置

### 固件（`mecanum_car.ino`）

| 参数 | 值 | 说明 |
|------|----|------|
| `PWM_FREQ_HZ` | 20000 | PWM 频率，超声波范围，消除啸叫 |
| `MIN_PWM` | 80 | 低于此 PWM 直接停车，防止部分供电嗡嗡响 |
| `CMD_TIMEOUT_MS` | 1000 | 连接状态下无指令超时停车 |
| `TEST_DURATION` | 3000 | 单电机测试时长 |
| `motorSpeed`（初始） | 180 | 手机模式默认速度，可被 `V` 指令修改 |

### 前端（`app.js`）

| 参数 | 值 | 说明 |
|------|----|------|
| `DEADZONE` | 0.18 | 摇杆进入控制的死区 |
| `EXIT_ZONE` | 0.12 | 摇杆退出的迟滞阈值 |
| `ROT_FACTOR` | 1.0 | B/X 原地转圈速度 |
| `KEEPALIVE_MS` | 200 | 数值不变时重发周期（喂看门狗） |
| 发送限频 | 30ms | 变化指令的最小发送间隔 |
| `MAX_PWM` | 255 | 最大 PWM |

## 常见问题排查

**连接蓝牙后电机「嗡嗡」响但不转**

- 多为电机被部分供电却无法启动：已通过 `MIN_PWM=80`（小值直接停车）处理。
- 检查该电机接线是否牢固、齿轮箱是否卡死、轮子是否被挡住。
- 用 `T1~T4` 单独测试定位。

**某个轮子（如 R1）不转**

1. 串口发送对应测试指令（R1 为 `T3`）。
2. 交换该电机与相邻通道的电机线再测：
   - 故障跟着电机走 → 电机 / 电机线问题。
   - 故障固定在某通道 → 对应 TB6612 通道或接线问题。
3. 检查对应 TB6612 的 VM 供电与共地。

**手柄检测不到 / 按键无反应**

- 先在系统蓝牙中完成配对；使用 Chrome / Edge 并保持页面在前台。
- 按手柄任意按键激活；确认界面显示 `mapping: standard`。
- 非标准映射的手柄，按键 / 轴索引可能不同，需要在 `app.js` 中调整。

**按住方向 / 转圈约 1 秒后自动停止**

- 说明保活未生效；确认使用的是最新 `app.js`，长按期间应每 200ms 重发。

**浏览器无法选择蓝牙设备 / 提示不支持**

- 改用 Chrome / Edge；通过 `localhost` 或 `https://` 访问，不能用 `file://`。
- 确认系统蓝牙已开启、设备已上电并处于广播状态。

**电机有高频啸叫**

- 确认固件 `PWM_FREQ_HZ=20000` 已生效（设置顺序为先 `analogWrite` 再 `analogWriteFrequency`）。
